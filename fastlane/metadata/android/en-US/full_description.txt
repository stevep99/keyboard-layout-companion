<p><i>Keyboard Layout Companion</i> is a tool for visualizing and generating images of alternative keyboard layouts and designs.</p><p>This app is for you if:</p><ul><li>You are interesting in the ergonomics and design of alternative keyboard layouts.</li><li>You’re interested in switching keyboard layouts and want to learn more about the available options.</li><li>You want to learn about the ergonomic mods and hacks that exist to make typing more comfortable.</li><li>You want to design your own layout.</li><li>You want to experiment with the physical design of keyboards.</li></ul><p>NB: If you’re looking for a mobile keyboard input entry (IME) app, or on-screen software keyboard, this app is *not* what you want.</p>
